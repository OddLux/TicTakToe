# Backlog Refiner v3.1 - Loop-Native Autonomous Refinement

Caveman-ultra. Loop-native. Stateless reducer per iteration. One ticket per step.
Full read+write scope including one-shot worktree execution. Session package output.
BACKLOG.md is deprecated as a write target -- snapshot generated at session start only.

---

## Invocation and Session Init

Parse natural language parameters at invocation before writing `session.json`.

**Parse order:** preset first -> per-parameter overrides composable on top.

Preset activation:
- `aggressive`: "go fast", "burn through it", "trust the scores", "max throughput"
- `balanced`: "default", "normal run", "standard mode", "balanced" (default if nothing said)
- `conservative`: "careful", "low risk", "don't touch much", "conservative"
- `refine-only`: "just score", "analysis only", "no execution", "read-only run", "dry run"

Per-parameter overrides (composable):
- `max_tickets`: "do N tickets", "cap at N", "limit to N this run"
- `direction`: "oldest first"/"front" -> ascending dp-NNN; "newest first"/"back" -> descending; "dp-NNN,..." -> explicit
- `budget_reserve_pct`: "leave X% buffer", "keep X% in reserve", "save X% for later"
- `standard_threshold`: "execute at confidence X", "fire at X", "threshold X"
- `virgin_threshold`: "virgin threshold X", "first-pass bar X", "raise/lower virgin bar to X"
- `research_pass_cap`: "max N analyst passes", "N research rounds max"
- Virgin disable: "treat all tickets equally" / "ignore session history" / "no virgin penalty" -> `virgin_threshold = standard_threshold`

After parsing, read `goal` and `mission` from `goal-state.json` in the active provider's configuration directory (e.g. `~/.claude/` for Claude Code, or `~/.antigravity/` / `~/.gemini/` for Gemini/Antigravity) if present.

**Create session package directory** (before writing session.json):
```
.tickets/refinement-sessions/YYYY-MM-DD_<3-word-slug>/
  manifest.toml       (written now)
  BACKLOG_SNAPSHOT.md (generated from tickets now)
  TELEMETRY.md        (written at session end)
  per-ticket/         (one dp-NNN.md per processed ticket)
```

3-word slug: first 2 significant words from goal title (kebab) + hex(timestamp % 4096).
If `.tickets/refinement-sessions/` does not exist, create it.

**Generate `BACKLOG_SNAPSHOT.md`** at session start:
Glob all `.tickets/open/dp-NNN*.md` and `.tickets/open/dp-NNN*/TICKET.md`.
For each ticket extract: ID, area (from frontmatter or "?"), title (first `#` heading or filename),
agent_readiness (from frontmatter or "-"). Write as:

```markdown
# Backlog Snapshot -- YYYY-MM-DD HH:MM UTC
Generated by backlog-refiner v3.1 at session start. Source of truth: .tickets/open/.

## Open Tickets
| ID | Area | Title | Readiness |
|----|------|-------|-----------|
| dp-NNN | area | Title | 0-100 or - |
```

**Write `manifest.toml`**:
```toml
[session]
date = "YYYY-MM-DD"
slug = "word-word-word"
preset = "balanced"
direction = "front"
max_tickets = 10
goal = "<goal title or empty>"
status = "running"
started = "<iso-timestamp>"
ended = ""

[stats]
tickets_processed = 0
tickets_promoted = 0
one_shots_executed = 0
needs_human = 0
avg_delta = 0
budget_used_pct = 0
terminated = ""
```

Write `refiner-session.json` in the active provider's configuration directory (atomic: write `.tmp` then rename):

```json
{
  "session_id": "<iso-timestamp>",
  "started": "<iso-timestamp>",
  "package_dir": ".tickets/refinement-sessions/YYYY-MM-DD_<slug>",
  "goal": "<8-word title from goal-state.json or empty>",
  "mission": "<full sentence mission or empty>",
  "preset": "balanced",
  "direction": "front",
  "standard_threshold": 95,
  "virgin_threshold": 98,
  "ac_quality_gate": 25,
  "budget_reserve_pct": 15,
  "max_tickets": 10,
  "research_pass_cap": 3,
  "queue": ["dp-003", "dp-005", "..."],
  "cursor": 0,
  "processed": {},
  "one_shot_queue": [],
  "consecutive_errors": 0,
  "budget_pct_last": 0,
  "recovered": false,
  "status": "running"
}
```

Build queue: glob `.tickets/open/` for `dp-NNN*.md` and `dp-NNN/TICKET.md` patterns.
Extract IDs, sort per `direction`, cap at `max_tickets`.

Then self-schedule the first iteration:
`ScheduleWakeup(delaySeconds=60, reason="starting first ticket iteration", prompt="<loop-prompt-prose>")`

## The Loop Prompt (< 200 tokens, plain prose -- NEVER a slash command)

This is the EXACT prose passed to ScheduleWakeup on every reschedule. Copy verbatim.

```
You are one iteration of Backlog Refiner v3. Your memory is `refiner-session.json` in your active provider's configuration directory (e.g. `~/.claude/` for Claude, `~/.antigravity/` / `~/.gemini/` for Gemini/Antigravity) -- re-read it now. It overrides anything you recall.

GUARDS (check first, cheapest to costliest):
  1. State missing/corrupt -> rebuild queue from .tickets/open/, set recovered=true, continue.
     If package_dir missing from recovered state: create new package (BACKLOG_SNAPSHOT + manifest) and store path.
  2. budget_pct >= (100 - budget_reserve_pct) OR queue[cursor] exhausted -> flush telemetry to package_dir/TELEMETRY.md, STOP.
  3. consecutive_errors >= 3 -> flush telemetry with terminated=errors to package_dir/TELEMETRY.md, STOP.
  4. queue[cursor] file missing -> mark skipped, advance cursor, continue.

STEP (one ticket):
  Load ticket. Promote to folder if flat (atomic). Read agent_readiness + pass count from TICKET.md.
  If passes >= research_pass_cap AND delta was <=2 last two sessions: mark needs-human, advance, reschedule.
  Spawn haiku analyst with CONTEXT BLOCK (from .agents/knowledge/refiner-rubric.md). Parse flat block output.
  Compute new confidence (4 sub-scores). If 60<=confidence<80 AND passes < research_pass_cap: spawn sonnet research agent (narrow).
  Update TICKET.md frontmatter (agent_readiness, suggested_model, readiness_history -- cap 5 entries).
  Write REFINEMENT.md (caveman-ultra: agents spawned, scores, decisions, this-session delta).
  Write per-ticket summary to package_dir/per-ticket/dp-NNN.md (same content as REFINEMENT.md this session).
  If confidence>=standard_threshold AND ac_quality==ac_quality_gate (or virgin gate): add to one_shot_queue.
  Advance cursor. Write state.json (atomic .tmp rename). Append to processed map.

ONE-SHOTS (only after queue exhausted, before telemetry dump):
  For each in one_shot_queue: spawn worktree implementor (suggested_model). Run ticket-bouncer.
  PASS: log commit hash. Update TICKET.md agent_readiness=100. Then run /close-ticket
    (which moves to .tickets/closed/, updates BACKLOG.md, and requires CHANGELOG.md update).
  BLOCK: set agent_readiness=85, log failure in REFINEMENT.md. Do NOT close or merge.

PERSIST + NEXT:
  Write telemetry dump to package_dir/TELEMETRY.md. Finalize package_dir/manifest.toml (ended, stats).
  Delete session.json.
  OR if queue not exhausted: ScheduleWakeup(delaySeconds=60, prompt="<this same prose verbatim>").
```

**CRITICAL:** The ScheduleWakeup `prompt` arg must be THIS prose verbatim. NEVER pass
`/backlog-refiner` or any slash command as the wakeup prompt (GH issue #51304: re-enters
command from top on an already-advanced task, losing in-loop progress).

## Haiku Ticket-Analyst

Spawn one haiku subagent per ticket. Description format (agent-spawn-labeling rule):
`[haiku-4.5] ticket-analyst: dp-NNN -- score implementation readiness`

**CONTEXT BLOCK** injected into prompt (< 400 tokens):

```
## MISSION
Score this ticket's implementation-readiness 0-100 (4 sub-scores x 25). Return flat block only.

## RUBRIC
(paste the 4-signal rubric section from .agents/knowledge/refiner-rubric.md -- read once at session start, cache in main context)

## KB INDEX
<titles + 1-line summaries of .agents/knowledge/* -- NOT full bodies>

## PRIOR
confidence=<N> passes=<N> delta_last=<N> (STALLED if delta<=2 two sessions)

## TICKET
<verbatim TICKET.md content>
```

**Expected analyst output -- flat fixed-key block, NOT JSON (~40 tokens vs ~90 for JSON):**

```
VERDICT
confidence: 84
ac_quality: 21
tier: sonnet-ready
delta: +12
missing: [impl-notes-depth, kb-coverage-missing-for-statusline]
needs_kb: [statusline.md]
blocker: none
suggested_model: sonnet
one_line: AC testable; impl notes thin; KB coverage partial.
```

Parser: line-oriented. `confidence:`, `ac_quality:`, `tier:`, `delta:`, `missing:`,
`needs_kb:`, `blocker:`, `suggested_model:`, `one_line:` keys.
- Missing `tier` line -> derive from confidence via tier table in `refiner-rubric.md`.
- Missing any other field -> empty, NOT crash.
- No `VERDICT` block found -> retry prompt once; second failure -> mark `error`, advance cursor.

## Sonnet Research Agent

Triggered when `60 <= confidence < 80` AND `passes < research_pass_cap`.
Description: `[sonnet-4.6] research: dp-NNN -- narrow KB + closed-ticket query`

```
Research agent for {ticket_id}. Read-only. Narrow query only.
QUESTION: What knowledge base entries, closed tickets, or ledger decisions
directly cover {ticket_title}?
Search: .agents/knowledge/ (grep {3 key terms}), .tickets/closed/ (same), decision-ledger.md.
Return flat block:
RESEARCH
confidence_boost: <0-25>
refs: [path:line - reason, ...]   (max 5)
open_questions: [<blocking question>, ...]
one_line: <what this resolved or failed to resolve>
```

Apply `confidence_boost` additively (cap total at 100). Update `passes` in TICKET.md.

## Opus Cross-Ticket Synthesis (legendary drop trigger)

Triggered at telemetry phase ONLY IF >= 3 monolith/needs-human tickets share apparent
root cause pattern. Description: `[opus-4.8] synthesis: cross-ticket -- find shared root cause`

```
Cross-ticket synthesis for {N} monolith tickets. Read only.
Tickets: {list}. Find the shared root cause pattern.
Propose 2-3 child scope splits per monolith that together implement the original goal.
Return a split proposal block per ticket. No prose outside the blocks.
```

## Folder Promotion (atomic, lazy first-touch)

When ticket is a flat file `.tickets/open/dp-NNN_slug.md`:
1. Read full content.
2. `mkdir .tickets/open/dp-NNN_slug/`
3. Write `.tickets/open/dp-NNN_slug/TICKET.md` (original content).
4. Write `.tickets/open/dp-NNN_slug/REFINEMENT.md` (empty stub with session header).
5. Delete the original flat `.tickets/open/dp-NNN_slug.md`.
6. All steps before delete = crash-safe: worst case leaves both flat + folder; re-run detects folder.

When ticket is already a folder (`dp-NNN_slug/TICKET.md`): no promotion needed.

## TICKET.md Frontmatter Fields (injected on first touch)

Add these three fields after **Status:** block if absent:

```markdown
**agent_readiness:** <0-100>
**suggested_model:** haiku|sonnet|opus
**readiness_history:** [{"session": "<date>", "confidence": <N>}, ...]
```

`readiness_history` cap: 5 entries (drop oldest). This is authoritative for
cross-session delta -- survives session file loss. Stored on ticket, NOT in session.json.

## Session Package (`.tickets/refinement-sessions/YYYY-MM-DD_<slug>/`)

Created at session init. Survives interruption (partial data preferred to no data).

```
refinement-sessions/
  YYYY-MM-DD_<3-word>/
    manifest.toml       -- config + live stats (updated at session end)
    BACKLOG_SNAPSHOT.md -- ticket table generated from .tickets/open/ at START
    TELEMETRY.md        -- full session telemetry (written at end, same format as before)
    per-ticket/
      dp-NNN.md         -- this-session REFINEMENT.md content (copy written per ticket)
```

**Path stored in `refiner-session.json` as `package_dir`** so loop iterations can find it
after ScheduleWakeup wakes a fresh agent with no memory of the previous run.

**On recovery (guard 1):** if `package_dir` is missing from rebuilt state, scan
`.tickets/refinement-sessions/` for a same-day package. If found, reuse it.
If not found, create a new one with `recovered=true` in manifest.

BACKLOG.md is **no longer written by the refiner**. Snapshot lives in the package.
To regenerate a fresh BACKLOG.md on demand:
```bash
uv run python scripts/generate_backlog.py   # (future script, not yet implemented)
```
Until that script exists: BACKLOG.md is frozen as a read-only reference. Do not write to it.

## State File: `refiner-session.json` (active provider's configuration directory)

Atomic write: always write to `refiner-session.json.tmp` then rename
over real file. A crash mid-write leaves last-good file intact.

On read: if file missing or JSON parse fails -> rebuild queue from `.tickets/open/`,
set `recovered=true`, restore `package_dir` by scanning `.tickets/refinement-sessions/` for
a same-day package (create new if none found), continue.

---

## Guard Sequence (top of every iteration, cheapest first)

1. State file missing/corrupt -> rebuild, `recovered=true`, restore `package_dir` (scan same-day or create), continue.
2. `budget_pct >= (100 - budget_reserve_pct)` OR `cursor >= len(queue)` -> flush telemetry to `package_dir/TELEMETRY.md`, STOP.
3. `consecutive_errors >= 3` -> flush telemetry (`terminated=errors`) to `package_dir/TELEMETRY.md`, STOP.
4. `queue[cursor]` file missing -> mark `skipped`, advance cursor, continue.
